## 1. Canonical finite formula

Let \(M=qW\), \(d_{ij}=\gcd(v_i,v_j,M)\), and
\(D_{ij}=M/d_{ij}\). The quotient
\[
L_{ij}^*/\mathbb Z^2
\]
is generated by
\[
\left(\frac{v_i}{M},\frac{v_j}{M}\right)
\]
and has order \(D_{ij}\). Thus every class is represented uniquely by
\[
\eta_k=\left(
\left\{\frac{k v_i}{M}\right\},
\left\{\frac{k v_j}{M}\right\}
\right),\qquad 0\le k<D_{ij}.
\]
Because the interval \([1/q,1-1/q]\) has length \(1-2/q<1\),
each class has at most one representative in that interval. Therefore
\[
\mathcal Q_{ij}
=\left\{\eta_k:
\frac1q\le\left\{\frac{k v_i}{M}\right\}\le1-\frac1q,\ 
\frac1q\le\left\{\frac{k v_j}{M}\right\}\le1-\frac1q
\right\}.
\]
This is **PROVED**.

## 2. Safe-coordinate weight

Define
\[
z_i(k)=\left\{\frac{k v_i}{M}\right\},\qquad
h_q(z)=\frac1{\alpha_q}
\left(1-\frac{|z-1/2|}{\alpha_q}\right)_+.
\]
Then \(h_q(z)>0\) exactly when
\[
\|z\|_{\mathbb R/\mathbb Z}\ge\frac1q.
\]
Consequently,
\[
T_{ij}=\frac1{D_{ij}}\sum_{k\in K_{ij}}h_q(z_i(k))h_q(z_j(k)).
\]
The different denominators \(D_{ij}\) prevent a direct common-\(k\) identity
with the pair sums as originally normalized.

However, lifting each pair to the common group \(\mathbb Z/M\mathbb Z\)
gives the exact global identity
\[
\boxed{
\sum_{i<j}T_{ij}
=\frac1M\sum_{k=0}^{M-1}\sum_{i<j}h_q(z_i(k))h_q(z_j(k)).
}                                                               \tag{1}
\]
This follows because each pair's \(D_{ij}\) classes occur with multiplicity
\(M/D_{ij}\) among \(k\bmod M\).

Writing \(H_k=\sum_i h_q(z_i(k))\), (1) becomes
\[
\sum_{i<j}T_{ij}
=\frac1{2M}\sum_{k=0}^{M-1}
\left(H_k^2-\sum_i h_q(z_i(k))^2\right).                       \tag{2}
\]
This is a weighted second-moment identity. It is not determined solely by
\(|S_k|\), because the positive weights vary with distance from the safe-box
boundary.

## 3. Axis subtraction identity

Let \(A_i\) be the complete signed sum on the \(i\)-axis, including its
origin. Then
\[
F_{\rm axis}=\sum_i A_i-(N-1),
\]
and
\[
\sum_{i<j}T_{ij}
=\binom N2+\sum_i(N-1)A_i+F_2.
\]
Therefore
\[
\boxed{
F_{\le2}
=\sum_{i<j}T_{ij}
-(N-2)F_{\rm axis}
-\frac{(N-1)(N-2)}2.
}                                                               \tag{3}
\]
This is **PROVED**.
