# TASK 24 — Localized Low-Multiplicity Certificate

## Starting point

TASK 23 proves that the global all-triple surplus is controlled by
intersections through order four, but divisor alignment does not make it
negative. Harmless overlap classes can outweigh existing multiplicity-zero
classes, as in $(1,2,3,4,5,7)$.

## Objective

Construct a phase-sensitive localized or weighted statistic which forces
$h_0>0$ without requiring the global surplus to be negative, or disprove a
precisely stated candidate by compact canonical-grid data.

## Required work

1. Partition the lcm grid using labelled transition boundaries or phase
   fibers, and define the statistic before inspecting safe points.
2. Prove exactly how negativity or another signed condition implies
   $m(z)=0$ somewhere.
3. Derive the statistic from bounded-order CRT intersections whenever
   possible and state the required order.
4. Test whether weighting down multiplicities $m\ge2$ preserves a rigorous
   implication while avoiding the TASK 23 counterexample.
5. Use divisor-compatible phase records, not arbitrary modular subsets.
6. Test $(1,3,4,5)$, all TASK 14 obstructions, $(1,4,5,6,9)$,
   $(1,2,3,4,5,7)$, and every applicable required family.
7. Search only the canonical lcm period and store compact phase/fiber data for
   each decisive counterexample.
8. Update global status and create `TASK25.md` only after genuine progress.
